Сюда кладём свои треки для блока «Кастомный динамик».

Форматы: .ogg (рекомендуется), .wav, .mp3.
Имя файла без расширения = имя трека в меню, порядок алфавитный.

МАКСИМУМ 64 ФАЙЛА. Файлы сверх 64-го будут видны в списке, но выбрать
их не выйдет: номер трека хранится в самом блоке, а места там 6 бит.

Файлы должны лежать у КАЖДОГО игрока и быть одинаковыми: по сети едет
номер трека, а не имя файла. Звук воспроизводится локально на каждом
клиенте, по сети летит только команда «играть/стоп».

После добавления файлов достаточно выполнить в консоли (F1):
    cspeaker rescan
